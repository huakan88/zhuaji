# 可学之处（2.15）

调研时间：2026 年 10 月。只看应用商店介绍、官网和公开评测，学交互和信息架构。不抄界面素材，不抄商标，不拆安装包。上一份功能盘点在 [竞品调研](competitor-research.md)。

落地范围停在现有四个底栏：今天、健康、粮仓、猫咪。包名、启动图标和已有功能都不动。

## PawDiary / 爪记一类日记

公开页把一天收成一条时间线：吃饭、梳毛、午睡各占一行，月份分组，空的时候像一本还没写的本子，而不是一张表格。

可学：

1. 今天先回答「现在要做什么」，再回答「接下来几天」。待办和更远的提醒不要混成一列。
2. 空状态用一幅小图和一句短话，不要解释整套功能。
3. 记录按时间从近到远排，日期靠右，眼睛能顺着扫。
4. 同一只猫的日常和健康不要分成两套互不相干的语言。

花爪：今天页分成「今天要办」和「接下来」。空的时候只留一句「今天清静」。猫咪页和健康页的最近记录改成带日期的时间线。

不学：必须订阅才能写日记；打卡连续天数；把日记做成可分享的性格卡片或社交帖。

来源：[Paw Diary](https://apps.apple.com/us/app/paw-diary/id6642710952)、[PawDiary for Pet](https://apprecs.com/ios/6737019466/pawdiary-for-pet)、[Meow Diary](https://meowdiaryapp.com/en/)

## AI PET 及同类助手

Pawli、AI PET 一类把扫粮结果做成商品页：品牌、名称、规格、配料分开，再给出提醒入口。首页常用三四个大按钮，而不是先填一张表。

可学：

1. 扫到的粮先看品牌和规格，配料另起一块，来源和修正日期放在脚注。
2. 健康记录用大按钮和预设（疫苗名、驱虫药名），日期用点选。
3. 多猫时每只猫的待办分开，不要把两只猫的事叠在同一行。
4. 给兽医看的摘要保持可复制的纯文本，不必先做聊天。

花爪：扫码命中页改成商品卡片，品牌、规格、配料分层；本机库和共享库的修正日期仍写在脚注。健康页顶部是「记体重 / 记疫苗 / 记驱虫」。疫苗和驱虫仍用已有的预设和「记下」。

不学：把成分扫描说成诊断；聊天问诊；Face ID 和账号墙；为了解锁记录而订阅。

来源：[Pawli](https://apps.apple.com/us/app/pawli-cat-health-food-scan/id6759465992)、[AI PET](https://apps.apple.com/us/app/ai-pet-dog-cat-vet-health/id6751818150)

## 小佩 Petkit、小米有品宠物

小佩公开功能是设备自动记下进食、饮水和如厕，余粮不足再提醒，多猫按体重或面部分开。离开设备之后，App 自己的记录很薄。小米有品一侧更多是设备说明书和商城，公开的独立健康档案不多。

可学：

1. 能自动知道的事不要再让人打字。已经扫到的条码、上次的驱虫药、今天/昨天/前天，继续一点即记。
2. 粮的状态用「还能吃几天 / 快到期」而不是一长串字段。
3. 多猫切换要看得见另一只有没有事。
4. 列表紧一点，一张卡片只留标题、一句说明和一个完成动作。

花爪：今天的待办行更紧，右侧只留日期和勾。粮仓搜索和扫码留在顶上。多猫胶囊上的件数保留。

不学：绑定硬件才能用；社区信息流；商城和优惠；为了识别猫而上传正脸。

来源：[小佩宠物](https://apps.apple.com/cn/app/%E5%B0%8F%E4%BD%A9%E5%AE%A0%E7%89%A9/id850263595)、[小米应用商店](https://app.mi.com/details?id=com.petkit.android)

## Rover、PetDesk、Whistle、Sure Petcare

Rover 的公开页是找寄养和遛狗的人，档案卡片强调「这是谁、在哪、能不能接」。PetDesk 把诊所写下的疫苗和复诊推到主人手机，并让人转发给美容或寄养。Whistle 用项圈把活动和位置收成今天的一条摘要。Sure Petcare 用猫门和喂食器把「谁进来了、吃了多少」做成按宠物分开的时间线。

可学：

1. 档案卡片先是照片和名字，下面才是品种、年龄、体重，像一张介绍，而不是表单。
2. 健康记录要能整段复制给别人，不必先做诊所账号。
3. 今天的摘要只保留即将发生的事，历史放到时间线。
4. 浅色用大面积留白和一种安静的颜色；深色用同一套结构，只换颜色。

花爪：猫咪页在照片下加品种和年龄两行，浅色仍是浅绿和白，深色走已有的深灰绿。复制健康卡保留。今天页不再把 30 天内的事和当天到期写在同一个标题下。

不学：预约市场和评价陌生人；诊所积分和保险推销；项圈定位；猫门曲线；广告开屏。

来源：[Rover](https://www.rover.com/)、[PetDesk](https://apps.apple.com/us/app/petdesk/id631377773)、[Whistle](https://www.whistle.com/)、[Sure Petcare](https://www.surepetcare.com/)

## 2.16 又落地的

粮仓每一袋只留一句状态：还能吃几天、快吃完，或快到期。吃完和包装日期哪个更近，就显示哪个，不再并排两个倒计时。这袋粮的详情先给这句话，生产、到期、开封仍留在下面。

健康页在三个大按钮下加「再记上次的驱虫药」，点一下就按今天记下，不用再进表单。另一只猫有没有事，仍看今天页胶囊上的件数，不另起一行。

猫咪档案把体重收进品种和年龄下面，点体重去称。浅色深绿字、白卡片不变。

## 明确不学

- 过重输入：长表单、自由填写病历、先注册才能记一笔。
- 广告、开屏、信息流和商城。
- 过度社交：动态、点赞、陌生人评价、分享卡片。
- 订阅才能看到自己已经记下的数据。
- 把模型回复写成诊断，或把未核实的营养数字填进空字段。
