# 少打字与接入智能设备调研（2.6 方案）

调研时间：2026 年 10 月。本文只做调研和方案，不改代码。价格、额度和接口以链接页面当时的内容为准。没查到的地方直接写「没查到」。

## 一句话结论

1. **最值得先做的是「替用户填好」**：默认今天、默认上次的品牌和医院、按间隔自动算下次，再加通知里一键「已完成」。这条不联网，不用新权限，不会出错。拍照、语音都做不到这么稳。
2. **拍照识别只做猫粮包装和疫苗贴纸**，继续用已经打包在 App 里的离线 ML Kit 中文识别。识别出的内容必须先让用户点一下确认才保存。手写的化验单和疫苗本识别率低，先不做。
3. **语音一句话记录可以做，但排在后面。** 国内大部分手机没有谷歌语音服务，系统自带的语音识别靠不住，只能自带离线模型（约 15–30MB）或接讯飞这类云服务。体验好，但会让安装包变大，或者要把录音传给第三方。
4. **智能设备里，现在能落地的只有蓝牙体重秤直连**：不需要账号、不收费、不联网。小米体脂秤 2 的广播格式已被社区公开解析，标准蓝牙秤有统一协议。用「抱猫称重 - 人的体重」就能得到猫的体重。
5. **猫砂盆、饮水机这类云设备，主流品牌都没有给普通 App 开放的公开接口。** 小佩、CATLINK、Litter-Robot、PetSafe 只有社区逆向的非官方接口，要用户交出账号密码，随时可能失效，不建议放进正式版。小米和涂鸦有官方开放平台，但要企业资质、商务签约或年费：涂鸦 App SDK 正式版首年 ¥33,500。
6. **想「一个平台接多个品牌」，涂鸦最接近**：它的猫砂盆标准数据里就有猫咪体重、每次排泄时长和每天次数。但普通用户授权的官方通道是给 Home Assistant 用的，没查到给第三方 App 公开申请的入口。适合等花爪有公司主体以后再谈。

## 一、花爪现在哪些地方要输入

| 位置 | 现在怎么填 | 还要用户做什么 |
| --- | --- | --- |
| 建猫档案 | 猫名是唯一的输入框；照片可拍照、选相册或用示例；品种、生日、绝育用点选和滚轮 | 打猫名 |
| 体重 | 从上次的体重开始，点「轻一点 / 重一点」，每次 0.05 kg | 先称好，再点几下 |
| 疫苗 | 点选疫苗名，选接种日期 | 选日期 |
| 驱虫 | 点选体内或体外，点选产品，选日期 | 选产品、选日期 |
| 就医 | 点选医院和原因，选日期 | 选医院、原因、日期 |
| 体检 | 点选项目，点「完成」 | 点选 |
| 慢病 | 从病种库里选 | 点选 |
| 扫粮 | 扫条码，查本地已有的粮；查不到就点「选品牌」；生产、开封、到期日期可以用离线文字识别读包装，再点开封后天数 | 对准条码；查不到时选品牌；确认日期 |
| 今天 | 待办旁边点勾 | 点一下 |

可以看出，花爪已经几乎不打字了。用户嫌麻烦的主要是这三件事：**要先在别处称好体重**、**每次都要选日期**，以及**查不到条码时要自己选品牌**。

## 二、六种简化输入方式对比

开发量按要改的部分估计：「小」是只改 Dart 页面和状态；「中」要新增一个插件或原生配置；「大」要加模型、后端或原生桌面组件。

| 方式 | 体验 | 准确度 | 国内用什么 | 开发量 | 隐私风险 |
| --- | --- | --- | --- | --- | --- |
| 智能默认值 + 上次值微调 | 打开就是填好的，点「保存」或「照旧」就行 | 最高。默认值来自用户自己的记录，错了也能看见 | 不用第三方，本地规则 | 小 | 无 |
| 快捷按钮、通知按钮、桌面小组件 | 不进 App，从桌面或通知点一下就完成 | 高，动作是固定的 | `quick_actions`（App 快捷方式）、`flutter_local_notifications`（已在用，可加按钮）、`home_widget`（桌面小组件） | 快捷方式和通知是中，桌面小组件是大（每个平台都要写原生界面） | 低 |
| 扫条码 | 对准就出结果 | 查得到时很准；但国内没有免费又全的公开猫粮条码库 | 已用 `mobile_scanner` 加本地库；可选国内付费查询接口或 Open Pet Food Facts | 小到中 | 低；联网查询会把条码发给第三方 |
| 拍照识别（OCR） | 拍一张，自动带出日期或疫苗名，再点确认 | 印刷的日期还行；疫苗本手写、化验单表格不稳 | 离线：ML Kit 中文识别（已打包）。云端：百度、腾讯 OCR，或通义千问 VL 这类看图模型 | 包装日期已做；疫苗贴纸是中；化验单是大 | 离线无；用云端时要上传照片，化验单属于健康信息 |
| 语音一句话 | 说「橘座今天 4.2 公斤」就记好 | 数字和猫名可以做到较准，要靠固定说法加规则拆解 | 离线：sherpa-onnx 中文模型。云端：讯飞听写。系统自带语音在国内手机上大多不可用 | 大 | 离线无；云端要上传录音 |
| 从设备自动同步 | 什么都不用做，数据自己进来 | 设备称重准；多猫时可能分错猫 | 蓝牙秤直连可行；猫砂盆、饮水机见第三部分 | 蓝牙秤是中；云设备是大，且受平台限制 | 蓝牙直连无；云接入要用户授权账号 |

### 1. 智能默认值和上次值微调（推荐第一）

- **体验**：日期默认今天，在纸条上方给「今天 / 昨天 / 前天」三个胶囊；驱虫默认上次的产品；就医默认上次的医院；疫苗和驱虫按间隔自动算出下次。今天页的待办点勾，就按默认值记一笔，不再弹出表单。
- **准确度**：最高。错了用户当场就能看到，改一下即可。
- **技术**：只用本地数据库已有的记录，不需要任何服务。花爪已经会按间隔算下次（`app_controller.dart` 里的 `intervalDays`），体重也已经从上次的值开始。
- **开发量**：小。要改疫苗、驱虫、就医、扫粮确认这几页的初始值，以及今天页「点勾」的行为。
- **隐私**：无。

### 2. 快捷按钮、通知按钮和桌面小组件

- **体验**：长按图标出现「称体重 / 记驱虫 / 扫粮」；到期提醒的通知里直接有「已驱虫」按钮；桌面小组件显示「下一件事」和一个按钮。
- **准确度**：高，每个按钮只做一件确定的事。
- **技术**：
  - App 快捷方式用 Flutter 官方的 [quick_actions](https://pub.dev/packages/quick_actions)，Android 7.1 起可用。
  - 通知按钮用已在用的 [flutter_local_notifications](https://pub.dev/packages/flutter_local_notifications)。
  - 桌面小组件用 [home_widget](https://pub.dev/packages/home_widget)。它不能用 Flutter 直接画小组件，Android 和 iOS 都要写原生界面；iOS 17 起才支持在小组件里直接点按钮（[说明](https://github.com/ABausG/home_widget/blob/dev/README.md)）。
  - 国内各家桌面（华为、小米等）对小组件的支持差异没查到统一资料，要真机测试。
- **开发量**：快捷方式和通知按钮是中；桌面小组件是大。
- **隐私**：低。小组件会在锁屏或桌面显示猫名和待办，要允许关掉。

### 3. 扫条码

- **体验**：已经有了。查不到时要选品牌。
- **准确度**：取决于条码库。
  - 中国物品编码中心有公开查询网站（[gds.org.cn](https://www.gds.org.cn/)，[查询方式说明](http://tiaomafuwu.com/?p=42890)），但**没查到**给 App 调用的公开接口和收费标准。
  - 第三方「商品条码查询 PRO」只覆盖国内注册条码，免费额度是匿名每天 2 次、登录每天 5 次，超出要付费（[文档](https://apizero.cn/aidocs/barcode-gs1)）。
  - [Open Pet Food Facts](https://world.openpetfoodfacts.org/data) 是免费的社区宠物食品库，要求「一次调用对应一次真实扫码」，可以下载全量数据。它的数据大多来自欧洲（[来源统计](https://world.openpetfoodfacts.org/facets/states/en:Characteristics%20to%20be%20completed/data-sources/1)），国内猫粮覆盖**没查到**数据，估计很少。
- **建议**：先把「这次选的品牌」记到这个条码上，同一袋粮第二次扫就能直接认出来。这比接外部库更省事。再随 App 内置常见国产猫粮的条码表。
- **开发量**：记住条码是小；接外部库是中，而且要做缓存和失败兜底。
- **隐私**：只用本地时无。联网查询会把条码发给第三方，条码本身不算个人信息。

### 4. 拍照识别（疫苗本、化验单、猫粮包装）

- **体验**：拍一张，自动带出日期和名称，在确认页用胶囊展示，点一下「对」即可保存。
- **准确度**：
  - 猫粮包装上的日期：印刷字，离线识别已经在用。主要误差是「生产日期」和「到期日」认反，需要确认页兜底。
  - 疫苗本：常见的是疫苗瓶贴纸（印刷）加医生手写的日期。贴纸上的疫苗名和批号可以识别；手写日期不稳，要让用户确认。
  - 化验单：是表格，项目多，单位多，离线识别只能拿到散字，需要表格识别或看图大模型。错一个数字就可能误导用户，风险高。
- **国内技术**：
  - 离线：ML Kit 中文文字识别 v2 的「打包版」把模型编进 App，不依赖谷歌服务，可以离线用（[官方说明](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)）。花爪已经在用。
  - 百度通用文字识别（高精度版）：实名个人每月 1,000 次免费，之后按量每次 ¥0.03 起（[免费额度](https://cloud.baidu.com/doc/OCR/s/fk3h7xu7h)，[价格](https://cloud.baidu.com/doc/OCR/s/9k3h7xuv6)）。
  - 腾讯云通用印刷体识别：每月 1,000 次免费，当月有效（[免费额度](https://cloud.tencent.com/document/product/866/35945)）。
  - 看图大模型：阿里云百炼 qwen-vl-plus（北京）原价是输入每百万 tokens ¥0.8、输出每百万 tokens ¥2（[价格](https://help.aliyun.com/zh/model-studio/qwen-vl-plus)）。它能直接把化验单整理成结构化内容，但同样要上传照片。
- **开发量**：疫苗贴纸是中，要写一套「疫苗名、批号、日期」的规则；化验单是大，还要服务端中转来保管云服务的密钥，花爪的 `server/` 可以承担。
- **隐私**：离线识别没有风险。用云端时要上传照片，照片里可能有主人姓名、电话和医院信息，化验单还属于健康信息。按要求要在隐私政策里逐项写明第三方 SDK、用途和收集的信息，并在用户同意之后才初始化（[讯飞开发者合规指引](https://www.xfyun.cn/doc/policy/personal_privacy.html)，[网信办 App 个人信息收集使用规定征求意见稿](https://app.xinhuanet.com/news/article.html?articleId=581ad76a66953b8e53596fb082e3c35e)）。

### 5. 语音一句话记录

- **体验**：按住说「橘座今天 4.2 公斤」，松手后显示「橘座 · 体重 4.20 kg · 今天」三个胶囊，点「记下」保存。
- **准确度**：语音转文字之后，用固定说法加规则拆解：猫名从已有猫里匹配，数字加单位识别成体重，疫苗、驱虫的名字从已有清单里匹配。不需要大模型。说法越固定越准，猫名是生僻字时容易错，所以必须有确认这一步。
- **国内技术**：
  - 系统自带语音：Flutter 常用的 `speech_to_text` 依赖系统语音识别服务。国内的华为、红米等手机没有谷歌语音服务，经常不可用甚至闪退（[问题 307](https://github.com/csdcorp/speech_to_text/issues/307)，[问题 336](https://github.com/csdcorp/speech_to_text/issues/336)）。有项目改用手机厂商自带的识别引擎，也只在部分机型上可用（[示例](https://github.com/openclaw/openclaw/pull/38691)）。**不能作为主方案。**
  - 离线：[sherpa-onnx](https://pub.dev/packages/sherpa_onnx) 有 Flutter 包，支持 Android arm64，提供中文流式模型。14M 参数的小模型最快，但准确率一般；中英双语模型更准（[模型说明](https://k2-fsa.github.io/sherpa/onnx/android/apk-cn.html)）。代价是安装包变大，具体大小要实测。
  - 云端：讯飞语音听写（流式版）创建应用后默认每天 500 次（[接口文档](https://www.xfyun.cn/doc/asr/voicedictation/API.html)），方言要另外购买，¥2,000 每个每年（[服务说明](https://static.xfyun.cn/doc/asr/voicedictation/voicedictation-description.html)）。讯飞离线听写只支持 Android，免费试用 10 台装机、90 天，正式价格要申请咨询（[离线说明](https://www.xfyun.cn/doc/asr/offline_iat/offline_iat-description.html)）。
- **开发量**：大。要加录音权限、模型资源或云服务、拆解规则和确认页。
- **隐私**：离线没有风险。用云端时要上传录音，必须单独申请麦克风权限，并且只在用户按住说话时录音（同上征求意见稿第十四条）。

### 6. 从设备自动同步

详见第三部分。结论：**蓝牙秤直连**可以做；**猫砂盆和饮水机**目前没有能放进正式版的稳妥接口。

## 三、能不能接第三方智能设备

### 总表

| 品牌 / 平台 | 有没有官方公开接口 | 怎么申请、收不收费 | 能拿到什么（公开资料可见的） | 结论 |
| --- | --- | --- | --- | --- |
| 小佩 PETKIT | **没有**。没查到官方开放平台 | 无。社区接口要用户的小佩账号密码 | 猫砂盆：每只猫最近一次如厕测得的体重、如厕时长、当天次数。饮水机：当天饮水次数和时长（蓝牙读取） | 只能走逆向，不建议放进正式版 |
| CATLINK | **没有**。没查到官方开放平台 | 无。社区接口用 CATLINK 手机号和密码 | 猫砂重量、清理次数、工作状态、日志；官方 App 里有每只猫的体重和如厕次数 | 同上 |
| 鸟小子 | **没查到**这个品牌的智能设备和开放资料 | — | — | 名字相近的「鸟语花香」有 App 控制的猫砂盆，但它的开放情况也**没查到** |
| 拓稍 PetSafe | **没有**公开文档 | 无。社区逆向了它的云接口 | ScoopFree 猫砂盆的状态、耙砂次数、活动记录。部分新款其实是涂鸦方案，可以加进智能生活 App | 同上；涂鸦款可以走涂鸦 |
| Whisker Litter-Robot | **没有**。社区库写明「目前没有公开接口」 | 无。社区接口用 Whisker 账号 | 每只猫的体重历史和每天如厕次数（Litter-Robot 4/5） | 同上；国内销量少 |
| 小米 / 米家 | **有**，但门槛高 | 要同时成为小米 IoT 和小米开放平台的**企业开发者**；开发阶段限频，上线要签商务协议。官方 Home Assistant 插件的许可证**禁止**用来开发 App | 米家规格里的猫砂盆有「本次入厕猫咪体重（克）」「本次如厕时长」「猫咪 ID」；小米饮水机规格只有缺水、滤芯等，**没有饮水量** | 有公司主体后可以申请；个人项目走不通 |
| 涂鸦 / 智能生活 | **有** | 云开发：免费体验版每月约 3 万次接口调用，但设备要用开发者自己的 App 账号关联，一个账号最多关联 2 个项目，不适合普通用户。自有 App 用 App SDK：开发版免费，限 100 个用户、不能商用；正式版首年 ¥33,500，次年 ¥13,000 | 猫砂盆标准数据：猫咪体重（克）、每次排泄时长、每天排泄次数、集便仓满。饮水机标准数据：水位、TDS、用水时长、滤芯寿命，**没有按次饮水** | 一个平台能覆盖多个品牌，最省事，但要付费并签约 |
| 华为 HiLink | 面向设备厂商，**没查到**让第三方 App 读取设备数据的公开接口 | 华为运动健康服务能读「人」的身高体重，需要企业资质和审核 | 宠物设备数据：没查到 | 走不通 |
| 小米体重秤 | 不需要接口，直接读蓝牙广播 | 免费 | 体脂秤 2 用蓝牙广播发出重量，格式已被社区公开 | 推荐 |
| 标准蓝牙秤 | 蓝牙联盟的公开标准 | 免费 | 重量，可选时间戳和用户编号 | 推荐 |

### 各家细节和来源

**小佩 PETKIT**
- 第三方 API 目录记录小佩「没有公开的开发者门户或公开 API」，只有社区逆向的接口（[apis.io](https://apis.io/providers/petkit/)）。
- 社区库：[py-petkit-api](https://github.com/Jezza34000/py-petkit-api/)、[petkit-api](https://pypi.org/project/petkit-api/)。后者写明「同一账号只能在一台设备登录，用这个库会把手机 App 挤下线」。
- 数据：社区的 Home Assistant 插件提供每只猫的「最近体重」「上次如厕时长」，以及猫砂盆的「今日使用次数」（[home-assistant-petkit](https://github.com/RobertD502/home-assistant-petkit)）。
- 饮水机：可以用蓝牙直接读到当天饮水次数和饮水时长（[petkit-local](https://github.com/b12e/petkit-local)），但同一页面也写明猫砂盆和喂食器的蓝牙只能配网，数据全在云端。
- 风险：接口不加密、随时可能改；要用户交出账号密码，并且会把用户挤下线。

**CATLINK**
- 没查到官方开放平台。社区插件用 CATLINK 手机号和密码登录，默认连中国服务器（[hasscc/catlink](https://github.com/hasscc/catlink/)，[社区讨论](https://community.home-assistant.io/t/catlink-scooper-smart-litter-box/522497)）。
- 官方介绍里，多猫按体重区分，建议体重差至少 300–500 克（[CATLINK 说明](https://www.catlinkus.com/blogs/news/cat-litter-box-self-cleaning-health-data-guide)）。

**Whisker Litter-Robot**
- 社区库写明是逆向，「目前没有公开 API，可能随时失效」（[pylitterbot](https://github.com/natekspencer/pylitterbot/)）。
- Home Assistant 官方集成提供每只猫的体重和「今日如厕次数」，只支持 Litter-Robot 4 和 5（[Whisker 集成](https://www.home-assistant.io/integrations/litterrobot/)）。

**PetSafe**
- 社区逆向的接口文档（[petsafe-api-documentation](https://github.com/ThomasHFWright/petsafe-api-documentation)），没查到官方公开接口。
- 有用户说 ScoopFree SmartSpin 其实是涂鸦方案，可以加进智能生活 App，再用涂鸦接入（[讨论](https://github.com/dcmeglio/homeassistant-petsafe/issues/26)）。

**小米 / 米家**
- 第三方应用控制米家设备，要成为小米 IoT 和小米开放平台的企业开发者；开发阶段有频率和次数限制，上线要申请并签商务协议（[整理](https://www.iotstu.com/post/86.html)，[小米 IoT 文档中心](https://iot.mi.com/v2/new/doc/home)）。账号授权的权限 6004 是「第三方服务商访问并控制小米用户的小米设备」（[权限列表](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1518)）。
- 小米官方的 Home Assistant 插件用 OAuth 登录，但许可证写明只能「为非商业性目的使用 Home Assistant」，**不授权用于开发 App、Web 服务等**（[LICENSE](https://github.com/XiaoMi/ha_xiaomi_home/blob/main/LICENSE.md)）。所以不能借它的接口。
- 数据：
  - 小顽智能猫砂盆有「本次入厕猫咪体重（g）」「本次如厕时长（秒）」「猫咪 ID，用于多猫识别」「如厕过少 / 频繁」（[mmgg.litter_box.lbc1](https://home.miot-spec.com/spec/mmgg.litter_box.lbc1)）。
  - 聚宠猫砂盆还有「本次便便重量」（[petjc.litter_box.pro](https://home.miot-spec.com/spec/petjc.litter_box.pro)）。
  - 米家智能宠物饮水机只有缺水、滤芯、水泵等状态，没有饮水量（[mmgg.pet_waterer.s1](https://home.miot-spec.com/spec/mmgg.pet_waterer.s1)）。

**涂鸦 / 智能生活**
- 云开发：免费体验版每月约 3 万次接口调用、14 万条消息，超出就停用（[定价](https://developer.tuya.com/cn/docs/iot/membership-service?id=K9m8k45jwvg9j)）。设备要用「关联涂鸦 App 账号」的方式扫码关联到开发者的云项目，一个 App 账号最多关联 2 个项目（[关联设备](https://developer.tuya.com/en/docs/iot/link-devices?id=Ka471nu1sfmkl)）。这适合自己家用，不适合给每个用户开通。
- 自有 App 用智能生活 App SDK：开发版免费，限每月 100 万次请求、100 个注册用户，只能用于非商业场景；正式版首年 ¥33,500，次年 ¥13,000，一个年费只对应一个 App（[App SDK 定价](https://developer.tuya.com/cn/docs/app-development/app-sdk-price?id=Kbu0tcr2cbx3o)）。
- Home Assistant 的涂鸦集成改用了「设备共享 SDK」，用户扫码就能授权，不需要开发者账号（[集成说明](https://www.home-assistant.io/integrations/tuya/)，[SDK](https://github.com/tuya/tuya-device-sharing-sdk)）。但它用的是 Home Assistant 的应用注册，**没查到**第三方 App 自己申请这类注册的公开流程。
- 数据：
  - 猫砂盆标准状态有 `cat_weight`（喵咪体重，克）、`excretion_time_day`（每次排泄时长）、`excretion_times_day`（每天排泄次数），以及集便仓满等通知（[猫砂盆标准状态集](https://developer.tuya.com/cn/docs/iot/s?id=Kakg3srr4ora7)）。
  - 饮水机标准状态有水位、TDS、水泵时长、滤芯寿命、用水时长（[饮水机标准状态集](https://developer.tuya.com/en/docs/iot/s?id=K9gf48r0as4ln)）。
  - 实际每款设备上报哪些数据由厂商决定，要按型号核对。

**华为 HiLink 和运动健康**
- HiLink 的接口是给设备厂商实现设备端的（[HiLink Codelab](https://developer.huawei.com/consumer/cn/codelab/HiLink/index.html)，[HiLink API](https://developer.huawei.com/consumer/cn/doc/3090501)）。**没查到**第三方 App 读取 HiLink 宠物设备数据的公开接口。
- 华为运动健康服务能读「人」的身高体重，要在 AppGallery Connect 申请，审核约 10 个工作日；个人开发者的应用要先上架华为应用市场（[申请说明](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/health-apply)，[授权说明](https://developer.huawei.com/consumer/cn/doc/hmscore-guides/add-permissions-0000001050069726)）。它记录的是主人的体重，对猫没有直接用处。

**鸟小子**
- 在应用商店、京东和品牌库里都**没查到**叫「鸟小子」的宠物智能设备和 App。搜到的是名字相近的「鸟语花香 Pet Marvel」（[品牌页](https://web.maigoo.com/brand/4090109.html)，[猫砂盆](https://brand.chongso.com/goods-detail/996/)），它的猫砂盆支持 App 监测，但开放接口**没查到**。请用户确认品牌名。

**小米体重秤和其他蓝牙秤**
- 蓝牙联盟的 Weight Scale 服务（0x181D）是公开标准，规定了重量以及可选的时间和用户编号字段（[标准](https://www.bluetooth.com/wp-content/uploads/Files/Specification/HTML/WSS_v1.0.1/out/en/index-en.html)）。
- 小米体脂秤 2（MIBFS / XMTZC05HM）不用这个标准，而是在广播里发 13 字节数据，用 0x181B 服务。重量是第 11–12 字节除以 200 得到公斤，并且有「已稳定」标志，不用配对（[格式说明](https://github.com/freenetwork/ble-in-xiaomi/blob/master/doc/devices/huami.health.scale2.md)，[讨论](https://github.com/KristianP26/ble-scale-sync/issues/134)）。
- 开源 App openScale 支持小米、云麦、华为荣耀等几十款秤（[支持列表](https://github.com/oliexdev/openScale/wiki/Supported-scales-in-openScale)）。华为 Scale 3 要先输入设备密钥才回应，不适合普通用户。
- 秤是给人用的，直接称猫可能不准：猫站不稳，体重也偏轻，最低称重读数**没查到**官方数据。所以用「抱猫称一次，再自己称一次，相减」。秤的读数精度要实测。

### 省事的路径

1. **蓝牙秤直连（推荐，2.6 就能做）**：不用账号、不收费、不联网、没有接口失效的风险。先支持小米体脂秤 2 的广播和标准 0x181D 秤。界面只有一个主操作：「站上去 → 抱猫站上去 → 记下」。App 会记住主人的体重，下次只要抱猫称一次。
2. **涂鸦一个平台接多品牌（等有公司主体）**：用标准数据就能拿到猫砂盆的体重、次数、时长。但商用要签约，并付 App SDK 年费，或者申请第三方授权通道（流程没查到），适合用户量起来以后再做。
3. **小米 IoT 开放平台（等有公司主体）**：小米猫砂盆的数据最全，但需要企业开发者资质和商务协议。
4. **逆向接口（不建议）**：小佩、CATLINK、Litter-Robot、PetSafe 都要用户交出账号密码，可能违反对方服务条款，接口随时会变，小佩还会把用户挤下线。最多做成「实验功能」，由用户自担风险，不进默认版本。
5. **截图兜底（可选）**：用户在设备 App 里截一张体重页，花爪用离线文字识别读出数字，再让用户确认。不涉及账号，但各家界面不同，准确度要实测。

## 四、每个输入点该用哪种方式

| 输入点 | 2.6 建议 | 以后可以加 |
| --- | --- | --- |
| 猫名 | 保留输入框；加「常用名」胶囊（如 橘座、咪咪、奶油） | 语音说名字 |
| 猫照片 | 不变 | — |
| 品种、生日、绝育 | 不变；生日默认「约 1 岁」 | 拍领养证明识别 |
| 体重 | 蓝牙秤一键读数（抱猫减人）；没有秤时保持现在的微调 | 涂鸦 / 小米猫砂盆同步；语音「4.2 公斤」 |
| 疫苗 | 日期默认今天，加「今天 / 昨天 / 前天」；下次按间隔自动算；通知里一键「已打」 | 拍疫苗贴纸，识别名称和批号 |
| 驱虫 | 默认上次的产品和类型；通知里一键「已驱虫」 | 拍药盒识别产品 |
| 就医 | 默认上次的医院；原因用常用胶囊 | 语音「今天去医院 拉肚子」 |
| 体检 | 不变 | 拍化验单（云端，用户单独同意） |
| 慢病 | 不变 | — |
| 扫粮 | 第一次选的品牌记到这个条码上；继续用离线文字识别读日期；开封日默认今天 | 内置常见国产粮条码表 |
| 今天待办 | 点勾直接按默认值记录，不弹表单 | 桌面小组件上点勾 |

## 五、推荐的 2.6 实施顺序

1. **默认值和「照旧」**：日期快捷胶囊，默认上次的产品和医院，今天页点勾直接记。只改 Dart 页面和状态，不加依赖。
2. **通知按钮和 App 快捷方式**：到期通知里加「已完成」，长按图标出现「称体重 / 记驱虫 / 扫粮」。用已在用的通知插件，再加 `quick_actions`。
3. **条码记忆**：扫到查不到的条码时，把用户选的品牌记到这个条码上，下次直接认出来。只改粮仓的数据写入。
4. **蓝牙秤直连**：支持小米体脂秤 2 的广播和标准 0x181D 秤，加「抱猫减人」流程。要新增蓝牙插件和定位或附近设备权限，并在隐私政策里写明。需要真机和真秤测试。
5. **拍疫苗贴纸**：沿用离线中文识别，新增疫苗名和批号的规则，识别结果走确认页。2.8 已做。
6. **桌面小组件**：显示下一件事。2.8 已做 Android，整块可点，日历页可以关掉待办显示。iOS 源码在 `ios/TodayWidget/`，要有付费开发者账号后在 Xcode 里加扩展才会出现在桌面。
7. **语音一句话（实验开关）**：先用 sherpa-onnx 离线模型加固定说法试点，量出安装包增加多少和识别准确度，再决定是否默认开启。
8. **云设备**：暂不做。等花爪有公司主体后，先谈涂鸦（多品牌）或小米 IoT（数据最全）。不在正式版里使用逆向接口。
