# 发版说明

这些正文对应已经发出的 GitHub Release。标签打在 `main` 上，不在功能分支上打。

安装包不放进仓库，也不挂到 Release 附件里。需要旁加载时，在仓库外传 APK。没有上传密钥时，包是 debug 签名，只能自己安装。

## v2.20.2

花爪 2.20.2（versionCode 37）。源码已是这一版。标签在合并进 `main` 之后再打，不在功能分支上打。

拍包装之后先核对再存进粮仓。品牌、品名、规格、配料、生产日期和到期日都能手改，并标上识别、请核对或未识别。条码不在本机表里时，拍包装进同一张表，条码已经填上。相机打不开、没认出字或看不清时，可以重拍或手填。到期日没读到就留空，这袋不会做临期提醒，也不会猜成一年后。今天页给有真实到期日的袋子一张临期卡。配料前几位按原文标出，不做风险评分。

认字用手机上的 ML Kit，照片不上传。条码仍是本机表和原来的免密钥公开库。没有会员，也没有需要付费才能用的识别。

包名、隐私门禁和底栏没变。

## v2.20.1

花爪 2.20.1（versionCode 36）。标签 `v2.20.1` 已在 `main`。Release：[v2.20.1](https://github.com/huakan88/zhuaji/releases/tag/v2.20.1)。

条码不在本机表里时，可以手写品牌、名称和规格并保存。拍包装用手机上的 ML Kit 认字。到期日没读到，或读得不够稳，就留空，不再默认成一年后。没写完的扫描和识别留在本机，关掉页面还能从「最近识别」接着填。

包名、隐私门禁和底栏没变。

## v2.20.0

花爪 2.20.0（versionCode 35）。标签 `v2.20.0` 已在 `main`。Release：[v2.20.0](https://github.com/huakan88/zhuaji/releases/tag/v2.20.0)。

搜不到、扫到无关码、同一天重复记和吃完一袋，都改成能看懂的下一步。健康页可以接着上次再记疫苗或驱虫。猫咪页可以点性别、绝育和生日。同一天再称，改的是原来那一条体重。

还没改的：选品牌仍会带出一款建议粮（室内成猫）；确认页记下之后回到今天；体重仍按千克显示。

## v2.19.0

花爪 2.19.0（versionCode 34）。标签 `v2.19.0` 已在 `main`。

扫到的粮在同一页写品牌、品名和规格。搜不到可以接着扫。健康页可以再记上次的疫苗。共享库没连上时，条码修正留在手机里，之后再发。
