# 发版说明

这些正文准备贴到 GitHub Release。已经在 `main` 上的标签可以直接用来建 Release。`v2.20.0` 和 `v2.20.1` 要等对应拉取请求合并进 `main` 之后再打，不要在功能分支上打这两个标签。

安装包不放进仓库，也不挂到 Release 附件里。需要旁加载时，在仓库外传 APK。没有上传密钥时，包是 debug 签名，只能自己安装。

## v2.20.1（草稿，标签未打）

花爪 2.20.1（versionCode 36）。

条码不在本机表里时，可以手写品牌、名称和规格并保存。拍包装用手机上的 ML Kit 认字。到期日没读到，或读得不够稳，就留空，不再默认成一年后。没写完的扫描和识别留在本机，关掉页面还能从「最近识别」接着填。

包名、隐私门禁和底栏没变。这一版不合并说明本身，合并进 `main` 之后再打附注标签 `v2.20.1`。

## v2.20.0（草稿，标签未打）

花爪 2.20.0（versionCode 35）。

搜不到、扫到无关码、同一天重复记和吃完一袋，都改成能看懂的下一步。健康页可以接着上次再记疫苗或驱虫。猫咪页可以点性别、绝育和生日。同一天再称，改的是原来那一条体重。

还没改的：选品牌仍会带出一款建议粮（室内成猫）；确认页记下之后回到今天；体重仍按千克显示。

合并进 `main` 之后再打附注标签 `v2.20.0`。

## v2.19.0

花爪 2.19.0（versionCode 34）。标签 `v2.19.0` 已在 `main`。

扫到的粮在同一页写品牌、品名和规格。搜不到可以接着扫。健康页可以再记上次的疫苗。共享库没连上时，条码修正留在手机里，之后再发。

## v2.18.2

花爪 2.18.2（versionCode 33）。标签 `v2.18.2` 已在 `main`。

固定选项旁边可以手写。空着不能记下，写上的按原文保存。性别仍是点选，体重仍按千克。

## v2.18.1

花爪 2.18.1（versionCode 32）。标签 `v2.18.1` 已在 `main`。

扫到本机猫粮或已经在粮仓里的那一袋，直接打开确认页或这袋粮。二维码里的条码和扫条码走同一条路。
